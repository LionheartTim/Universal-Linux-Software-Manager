# How to Install Universal Linux Software Manager v1.0.0

This guide explains how to install the downloaded **`.flatpak` application bundle**, including the graphical double-click method. The application ID is `io.github.LionheartTim.UniversalLinuxSoftwareManager`.

## 1. Installing by double-clicking (recommended for desktop users)

1. Download the `.flatpak` bundle from a trusted project release. A `.flatpak` is an application bundle, **not** a `.flatpakref` repository link.
2. Open your Downloads folder in your desktop's file manager (for example, **Dolphin** on KDE Plasma).
3. **Double-click** the file. Where Flatpak integration is configured, your software center (such as **KDE Discover**) opens and presents the package details.
4. Verify the application name and source, choose **Install**, and approve the requests from your operating system's installer.
5. Open **Universal Linux Software Manager** from the application menu. If the launcher does not show up after initial Flatpak setup, log out and back in.

**Prerequisites:** Your system must have Flatpak and suitable graphical software-center integration installed. The `.flatpak` bundle does not contain the complete KDE Platform runtime. The installer may download a compatible runtime over the internet, using a configured Flatpak remote. If double-clicking does nothing, use the terminal method below rather than bypassing security prompts.

## Why am I asked for my password more than once?

On KDE Plasma, a locally downloaded `.flatpak` can be opened in **KDE Discover**. Discover communicates with **Flatpak** and, for **system-wide** installation work, with the operating system's authorization mechanism (**PolicyKit / polkit**). Separate installation steps or required runtime dependencies can cause multiple administrator-password requests. For example, **three prompts were observed on an openSUSE test VM**.

The exact number and reason for each prompt depend on your Linux distribution, Discover/Flatpak version, system-versus-user installation choice, whether dependencies are already installed, and authorization caching. **The developer of Universal Linux Software Manager does not control these pre-launch prompts**, and they are not generated by the program itself. Do not enter a password into an unexpected dialog, and do not disable authentication to make the prompts disappear. Always verify the source and details of what your installer is asking to authorize.

A **per-user** Flatpak installation may avoid system administrator prompts, although confirmations and runtime downloads can still occur. See Step 3.

## 2. If Flatpak is not installed

Run `flatpak --version` in a terminal. If Flatpak is missing, install it using the appropriate package manager:

| Distribution | Flatpak installation |
|---|---|
| Debian, Ubuntu, Xubuntu, Lubuntu, Linux Mint | `sudo apt update && sudo apt install -y flatpak` |
| Arch Linux, Manjaro | `sudo pacman -S --needed flatpak` |
| Fedora (traditional DNF) | `sudo dnf install flatpak` |
| openSUSE (traditional Zypper) | `sudo zypper install flatpak` |
| Bazzite / Fedora Atomic | Flatpak is normally included. Check first; avoid unnecessary OS layering. |

For other distributions see https://flatpak.org/setup/. A fresh Xubuntu Xfce installation was observed without the Flatpak command; install Flatpak before trying the downloaded bundle.

Graphical installation additionally depends on your software center's Flatpak support. On some desktop environments a Flatpak-compatible software-center plugin must be installed separately; consult your distribution's documentation.

## 3. Terminal installation for the current user

If Flathub is not configured for your user, add it to make the required runtime available:

```bash
flatpak remote-add --user --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
```

Then install your downloaded local bundle, **using its actual pathname**:

```bash
flatpak install --user --bundle "$HOME/Downloads/UniversalLinuxSoftwareManager-v1.0.0.flatpak"
```

If your file has a different name or is on the Desktop, adjust the command accordingly. The filename above is an example. When asked to download the KDE runtime or approve the installation, review the details and confirm as appropriate.

Launch the installed application:

```bash
flatpak run io.github.LionheartTim.UniversalLinuxSoftwareManager
```

`--user` installs for the current account, not system-wide. A user installation may reduce administrator password prompts compared with the software center's system-wide installation route; this depends on your system configuration. **Do not assume the application itself is available on Flathub** merely because the runtime is fetched from there.

## 4. Check installation or uninstall

To list applications installed for the current user:

```bash
flatpak list --app --user
```

To uninstall the per-user installation:

```bash
flatpak uninstall --user io.github.LionheartTim.UniversalLinuxSoftwareManager
```

If it was installed system-wide, the user-scoped uninstall command will not remove that installation; use the system's graphical software manager or the appropriate Flatpak installation scope. Flatpak application data is not explicitly deleted by the commands above.

## 5. Backups and desktop restore

The app creates local `.bu` archives containing selected installer files and supported desktop settings. They are **unencrypted** and do not contain a complete disk/system image.

For supported **KDE Plasma** sessions, restoring desktop configuration files is normally **staged until the next login** to avoid Plasma overwriting them when the old session exits. The app verifies its systemd/KWin session requirements, reports when a restart is needed, and **never reboots automatically**. Audio restoration takes place separately after login. Restart into the same KDE session type and inspect the actual settings. Older or customized Plasma startup methods may not support this safe staging path.

Other supported desktop environments may also require a logout or reboot after restoring settings. Read the app's **Info** tab (**F1**) for the full user guide.

## Troubleshooting

- **`flatpak: command not found`** — Install Flatpak as in Step 2.
- **Double-click does not open an installer** — Verify the software center has Flatpak integration, or use Step 3.
- **Multiple password requests** — Read the explanation above; review each system authorization dialog rather than disabling security.
- **Runtime missing / no remote** — Configure Flathub for the appropriate installation scope; connect to the internet if runtime download is needed.
- **Cannot find the bundle** — Verify the actual path and case, for example `ls -lh "$HOME/Downloads/"*.flatpak`.
- **App installed but missing from the menu** — Sign out and back in after initial setup.
- **Native package action unavailable** — The app enables only the backends and operations supported on the running host.
- **KDE backup staged but not applied** — Confirm that the same KDE session starts after reboot, that the session uses a supported KWin systemd user service, and review the app's restoration status.
